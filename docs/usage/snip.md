# Snip

Press **⌃6** (Control+6) to enter Snip mode. The screen freezes and you can drag-select a region to copy to the clipboard.

## Modes

| Hotkey | Action |
|---|---|
| ⌃6 | Snip to clipboard |
| ⌃⇧6 | Snip to file (saves to ~/Pictures/ZoomacIt/) |

## Usage

1. Press **⌃6** (or **⌃⇧6** for file)
2. Screen freezes with a crosshair cursor
3. Drag to select a region
4. Release — the cropped image is copied to clipboard (or saved to file)
5. Press **Escape** to cancel without capturing

## Snip to File

When using ⌃⇧6, the screenshot is saved to `~/Pictures/ZoomacIt/` with a timestamp filename. A thumbnail notification appears — click it to reveal the file in Finder.

## Settings

| Setting | Description | Default |
|---|---|---|
| Snip hotkey | Key combo for clipboard snip | ⌃6 |
| Snip Save hotkey | Key combo for file snip | ⌃⇧6 |

## Permissions

Snip requires **Screen Recording** permission to capture the screen. You will be prompted on first use.
