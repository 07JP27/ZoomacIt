# Snip

**⌃6**（Control+6）を押すとSnipモードに入ります。画面がフリーズし、ドラッグで領域を選択してクリップボードにコピーできます。

## モード

| ホットキー | アクション |
|---|---|
| ⌃6 | クリップボードにスニップ |
| ⌃⇧6 | ファイルにスニップ（~/Pictures/ZoomacIt/ に保存）|

## 使い方

1. **⌃6**（またはファイル保存の場合 **⌃⇧6**）を押す
2. 画面がフリーズし、十字カーソルが表示される
3. ドラッグで領域を選択
4. リリース — 切り取った画像がクリップボードにコピー（またはファイルに保存）
5. **Escape** でキャプチャせずにキャンセル

## ファイルに保存

⌃⇧6を使用すると、スクリーンショットはタイムスタンプ付きのファイル名で `~/Pictures/ZoomacIt/` に保存されます。サムネイル通知が表示され、クリックするとFinderでファイルを表示します。

## 設定

| 設定 | 説明 | デフォルト |
|---|---|---|
| Snipホットキー | クリップボードスニップのキーコンボ | ⌃6 |
| Snip Saveホットキー | ファイルスニップのキーコンボ | ⌃⇧6 |

## 権限

Snipは画面キャプチャのために**画面収録**権限が必要です。初回使用時にプロンプトが表示されます。
