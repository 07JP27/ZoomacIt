# Record

**⌃5**（Control+5）を押すとフルスクリーン録画を開始します。3-2-1のカウントダウンが表示された後、録画が開始されます。

## 使い方

1. **⌃5** を押す — カウントダウンオーバーレイが表示（3… 2… 1…）
2. カウントダウン後に自動的に録画開始
3. **Escape** を押して録画停止
4. ビデオは `~/Movies/ZoomacIt/` にタイムスタンプ付きファイル名で保存

## 操作

| 入力 | アクション |
|---|---|
| ⌃5 | 録画開始 |
| Escape | 録画停止 |

## 出力

- **フォーマット**: MOV（AVAssetWriter経由のH.264）
- **保存先**: `~/Movies/ZoomacIt/`
- **ファイル名**: `ZoomacIt-YYYY-MM-DD-HHmmss.mov`

## 権限

Recordには以下の両方が必要です：
- **画面収録** — 画面コンテンツのキャプチャ
- **アクセシビリティ** — グローバルEscapeキー検出（アプリフォーカスなしで動作）

初回使用時にプロンプトが表示されます。
