# デモタイプ

**⌃7**（Control+7）を押すとデモタイプが起動します。ダイアログが表示され、タイプするテキストを入力します。**Type** をクリックすると、直前にフォーカスされていたアプリに一文字ずつタイプされます。

## 入力ダイアログ

| 要素 | 説明 |
|---|---|
| テキストフィールド | タイプする複数行テキスト（前回のテキストが自動入力） |
| Type ボタン | シミュレーションタイピングを開始 |
| Cancel ボタン | タイプせずにダイアログを閉じる |

## 設定

| 設定 | 説明 | デフォルト |
|---|---|---|
| ホットキー | デモタイプを起動するグローバルショートカット | ⌃7 |
| タイピング速度 | 1秒あたりの文字数 | 15 |

## 動作

- ダイアログには前回タイプしたテキストが自動入力されます — デモの繰り返しに便利
- **Type** をクリックすると、前のアプリにフォーカスが戻り、短い遅延の後にタイピングが開始されます
- タイピング速度は1〜200文字/秒の範囲に制限されます
- 改行とタブに対応（ReturnキーとTabキーとして入力）
- タイピング中にホットキーを再度押すと即座に停止します
- メニューバーアイコン → **DemoType** からも起動できます

## 必要条件

- キー入力をシミュレートするため、**アクセシビリティ権限**が必要です
- 初回使用時、macOSがシステム設定 → プライバシーとセキュリティ → アクセシビリティでアクセスを許可するよう求めます
